# Peaky Blinders

**Peaky Blinders** is a British period crime drama television series created by *Steven Knight*. Set in Birmingham, England, it follows the exploits of the **Shelby crime family** in the direct aftermath of the First World War.

> *"By order of the Peaky Blinders!"* — Arthur Shelby

---

## Main Characters

* **Thomas "Tommy" Shelby** – The ambitious and calculating leader of the Peaky Blinders.
* **Arthur Shelby** – The eldest Shelby brother and Tommy's right-hand man.
* **Polly Gray** – The matriarch of the Shelby family and treasurer of the gang.
* **Ada Thorne (née Shelby)** – The only sister of the Shelby brothers.
* **John Shelby** – The third-eldest brother and a key enforcer in the gang.
